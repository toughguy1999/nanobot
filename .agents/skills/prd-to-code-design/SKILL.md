description: 根据prd的内容，输出整体性的代码设计。当用户需要根据需求进行代码设计时使用。
--- 

## 步骤
1. 如果还未阅读代码库，先探索了解当前代码库
2. 先不要写文档，结合当前代码库，如果有不明确的技术性问题，逐个提问并给出推荐方案，不要忽略这个步骤！
3. 提问完成后，根据prd和问答环节输出一份技术性的代码设计文档。

## 要求
- 重心放在上层设计，注意当前模块划分的职责边界，以及新增代码的模块归属
- 注意：这是一份high-level的设计文档，只需要包含整体框架、关键技术决策等，不需要深入到函数的实现细节

## 验收标准
文档不超过400行，如果超过则按照以下顺序压缩：
1. 检查有无近似的概念，整合为一份 
2. 即使不写，也很容易想到的，直接删除 
3. 不重要的决策，精炼语言
